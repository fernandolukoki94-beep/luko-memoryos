# Luko Memories (MemoryOS) - Frontend

## O Cofre Digital da Sua Vida

Este é o frontend da aplicação Luko Memories, construído com React e Tailwind CSS para oferecer uma experiência de usuário moderna e responsiva.

## Tecnologias Utilizadas

- **Framework:** React
- **Estilização:** Tailwind CSS
- **Animações:** Framer Motion (a ser implementado)
- **Roteamento:** React Router DOM

## Estrutura do Projeto

```
frontend/
├── public/
├── src/
│   ├── assets/             # Imagens, ícones, etc.
│   ├── components/         # Componentes reutilizáveis
│   ├── context/            # Contextos React para gerenciamento de estado
│   ├── hooks/              # Hooks personalizados
│   ├── pages/              # Páginas principais da aplicação
│   ├── services/           # Funções para interação com a API do backend
│   └── styles/             # Ficheiros CSS globais e Tailwind
├── index.html              # Ficheiro HTML principal
├── package.json            # Dependências e scripts do projeto
├── tailwind.config.js      # Configuração do Tailwind CSS
└── vite.config.js          # Configuração do Vite
```

## Como Configurar e Executar (Desenvolvimento)

### Pré-requisitos
- Node.js (v18 ou superior)
- npm ou yarn

### Instalação e Execução

1. Navegue até o diretório `frontend`:
```bash
cd frontend
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

O frontend estará disponível em `http://localhost:5173`.
