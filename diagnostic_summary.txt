Diagnóstico Técnico:

2. Problema de Deploy: O Vercel estava exibindo o código-fonte (server/index.ts) em vez de servir o frontend.

4. Correção Aplicada:
   - Simplificação do build no package.json (apenas vite build).
   - Ajuste do outDir no vite.config.ts para 'dist'.
   - Criação de vercel.json com rewrites para SPA.
   - Remoção de scripts de analytics quebrados no index.html.
